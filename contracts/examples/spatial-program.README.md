# Synthetic execution-core example

Original synthetic program authored for ExhibitOS, CC0-1.0. Scene room/light IDs
refer to the redistributable public Spec exhibition fixture. The synthetic media
ID is only a capability/reference witness; no audio bytes, artwork or remote URL
are embedded. The compiled evaluator probe supplies a local reference scope and
changes its live audio capability. Emitting a command does not prove playback,
asset rights, public API authorization or a Viewer integration.

This standalone development program is not the existing OES disabled scripts
array, does not enable it, and is not an adopted public extension. Full Spec
adoption, editor/Viewer bindings and validated transport/profile bounds remain
follow-up work. Keep original base declarations unchanged.
