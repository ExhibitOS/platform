# ADR0011: bounded opt-in exhibition audio and isolated artwork detail

Status: implementation candidate; full integrated production qualification pending.

The existing public OES media inventory, audio zones (autoplayfalse and required transcript), and text annotations remain the portable base. Platform optional `org.exhibitos.viewer/experience` version1 adds bounded floor material assignments, placement voice/transcript/locale associations, artwork-local centered-meter annotation coordinates, room reverb and separate translations. The shared browser/API validator rejects unknown own versions/fields, invalid/case-aliased references and positions outside artwork bounds; absence remains backwards compatible. No private Capture implementation is required.

Exhibition editors upload only bounded PCM16 WAV, mono/stereo8–48kHz, at most60seconds/12MiB. A strict RIFF structure/hash check avoids implicit codec/metadata/remote-fetch support. Content and approval are immutable; current availability is a separate reversible flag. Current tenant/editor authorization, rights validity, immutable approval, revision and all asset hashes are rechecked at publication and anonymous metadata/byte access. Audio changes do not grant original artwork download/export rights. New migration008 retains audio source/approval/publicmedia rows and audit, with no deletion endpoint.

WebAudio context creation and media requests require an explicit sound/voice/zone action. Four original deterministic procedural footstep waveforms depend on actual grounded horizontal displacement and floor material; turns/collisions/pauses do not generate standing footsteps. Current/next authored room loading is bounded rather than full-gallery preload. Gain depends on distance and room, with short/long convolution reverb tied to room size and authored wet level. These synthesized choices are approximations, not measured acoustics or full physical sound propagation. Mute/volume/hidden/blur/Escape/detail/pause/dispose control lifecycle; transcripts remain readable on failure.

Artist recording uses user-selected getUserMedia permission and a same-origin AudioWorklet producing bounded monoPCM WAV locally; upload and approval are separate actions. Permission denial or unsupported hardware leaves file upload available. No microphone is opened on mount and no recording is posted automatically. [AudioWorklet](https://developer.mozilla.org/en-US/docs/Web/API/AudioWorklet) and [getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia) require a secure supporting context. [decodeAudioData](https://developer.mozilla.org/en-US/docs/Web/API/BaseAudioContext/decodeAudioData) is applied only after full bounded verified WAV bytes are available.

Detail is a separate scene with verified current public GLB/PNG, original dimensions, zoom/rotation, annotations, rights and explicitly available public provenance. The main Viewer stays mounted while navigation is suspended. Closing returns focus/position and previous walking state without acquiring pointer lock automatically. Proximity entry defaults off and remains separately selectable; arbitrary auto-zoom is not forced. Missing fields show missing rather than fabricated year/material. Translations do not replace author originals.

Root must execute independent install/check/E2E, actual PostgreSQL/media rights/restore and production browser recording/audio/detail tests, inspect screenshots and record exact-source evidence before accepting T04-03. Emulated microphone and WebAudio nodes do not prove actual microphone/speaker/device audibility. No new browser package or hosted/paid service is required; AGPL code and existing third-party notices remain.
