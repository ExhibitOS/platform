# ADR0022: centered artwork metre display and artifact affine composition

Status: implemented and qualified with bounded numeric/Rapier/server unit cases and actual Chromium React synthetic fixtures. Real authority/API deployment qualification and physical accuracy are separate evidence.

Base OES draft defines meter geometry, positive dimensionless XYZ scale, normalized XYZW quaternion and the order artifact then placement then room. Dimensions are assertions before the artifact transform and source-unit conversion is already baked into original bytes. The Platform display profile additionally chooses the measured GLTF scene centre as artwork-local anchor, matching ADR0011 centered-metre annotations. This is an explicit display/pivot policy, not an assertion that the base OES spec requires every consumer to recenter GLTF pivots.

For column vectors, model world coordinates are `R · P · A · T(-c) · N · v`, where c is the measured scene centre including authored GLTF node transforms N. Original positions, indices, normals, GLTF nodes and file bytes remain untouched. Centered annotations use `R · P · A · q`; the centre translation must not be applied again. Image planes start centered with declared physical dimensions and use the same A/P/R chain. No metadata dimension fitting or second import scale is applied. Artifact pose is part of the approved immutable artwork snapshot; Studio cannot edit it to bypass CMS/OEX approval.

Detail omits exhibition R/P, retains A and aims the camera/interactive rotation pivot at its measured transformed centre. Camera placement is a view operation, not another model scale or cancellation of artifact translation. Placeholder assertion bounds use A/P/R independently of measured mesh bounds.

Positive nonuniform scales and rotations can produce shear. Client collision therefore uses eight transformed assertion-box corners as an actual convex hull; server presence measures world Euclidean capsule-segment distance to the same affine hull, not an invented orthogonal box or an incorrectly scaled radius. These are conservative metadata collision envelopes, not actual mesh/physical reconstruction. Existing 4mm minimum collision depth remains an explicit navigation-envelope policy and never adds thickness to rendered geometry. Bounds/finite/pose limits fail closed. Server movement compares the continuous capsule-axis swept quadrilateral (two triangles, with boundary segments handling degenerate motion) against the actual hull surface in world Euclidean distance. No vertical sampling gaps or radius inflation from sample intervals remain. Server clearance includes the measured maximum corner displacement caused by Rapier Float32 conversion plus a 0.1 micrometre numerical margin, conservatively covering the rounded convex proxy by the convex-combination bound. This may reject near-contact paths and is not a promise of identical Rapier/contact solver behavior or actual physical mesh collision. Shared walking admission (128 placements, 32 rooms, 256 surfaces, 128 openings) rejects degenerate double-precision or Float32 hull geometry before creating either consumer.

Identity artifacts remain compatible. Qualification requires independent numeric goldens for noncommuting transforms, node preservation, annotations, images, planar bounds, shear collision and immutable API roundtrip plus real React controls/revocation. Rendering alone does not complete this contract, T06-03 LOD/quality or physical calibration.

Walking-profile bounds do not narrow base OES validation, stored CMS/library artifacts or nonwalking publications. Unsupported walking is explicitly rejected at client navigation and server presence creation, while text/nonwalking display remains independently available within renderer limits.

New placement defaults keep the placement origin nonnegative in room Y while retaining any upward authored artifact offset. Wall alignment may compensate the approved artifact offset to align assertion bounds, but refuses a resulting placement origin outside its OES room instead of producing an invalid draft or changing the artifact transform.
