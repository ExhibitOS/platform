## Fresh isolated checkout

`git clone --no-local` copied the committed repository to
`/private/tmp/exhibitos-platform-t00-02-fresh`; ignored operations and local config
were absent. The following portable form of the equivalent shell execution passed install, all checks,
build and all3 browser tests:

```sh
env -i \
  PATH="$NODE_RUNTIME_BIN:/usr/bin:/bin" \
  CI=true \
  npm_config_cache=/private/tmp/exhibitos-npm-cache \
  npm_config_userconfig=/dev/null \
  npm_config_globalconfig=/dev/null \
  npm_config_offline=true \
  npm_config_audit=false \
  PLAYWRIGHT_BROWSERS_PATH="$BROWSER_CACHE_DIR" \
  /bin/sh -c 'cd /private/tmp/exhibitos-platform-t00-02-fresh && ./scripts/verify.sh'
```

The original isolated invocation also used a temporary home directory; no home variable
is reassigned in these portable instructions. Define `NODE_RUNTIME_BIN` and
`BROWSER_CACHE_DIR` for the local installations before the invocation.
This used integrity-checked cache artifacts originally fetched from the public
registry. The initial env-cleared online `npm ci` waited on network audit and was
cancelled; offline/audit-disabled rerun succeeded. The fresh macOS installation
reported optional fsevents install scripts not approved by npm; all actual checks
passed without approving them. A new machine still requires public npm access
and installation of Chromium. No credential environment, user npmrc or private
repository is needed.
