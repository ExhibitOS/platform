# 오프닝과 소규모 교육 행사

상태: 개발 후보. 서버·브라우저·음성의 최종 통합 검증과 공개 릴리스는 별도로 기록합니다. 이 안내를 production 서비스 보장으로 사용하지 마세요.

## 참여와 교육 진행

공개 전시의 3D 관람에서 **오프닝 참여**를 선택합니다. 기본값은 혼자·무음 관람이며 글 대화, 음성 듣기와 안내 따라가기를 각각 선택합니다. 목록·작품 설명·대본은 별도 대안입니다. 글 관람에서 공간 안내를 사용하려면 3D 관람 시작을 명시적으로 선택하세요.

현재 로그인된 기관 관리자 또는 공개 전시의 소유 artist/curator만 **호스트로 참여**할 수 있습니다. 서버가 현재 세션·기관·소유·공개 revision을 확인해 일회용 60초 host grant를 발급하고, 참가와 주기적 검사에서도 다시 확인합니다. 화면의 역할이나 클라이언트 입력으로 호스트 권한을 얻을 수 없습니다.

호스트는 오프닝 시작, 저장된 시점의 안내 초대와 여기에서 만나기 초대를 선택합니다. 관람객은 초대를 직접 수락하거나 안내 따라가기에 동의합니다. 전달되는 것은 공개된 시점 ID이며 임의 카메라 좌표가 아닙니다. 기존 Viewer가 안전성을 검증한 뒤 이동합니다. 호스트 종료·음소거는 음성을 정지하고, 참가자가 다시 명시적으로 동의하기 전 마이크를 재시작하지 않습니다.

교육자는 먼저 자신의 공개 링크와 시작 위치를 확인하고 참여자에게 무음·글·대본 대안을 설명하세요. 참여자별 선택을 존중하고 시작→안내→질문→종료 순서로 진행합니다. 운영 호스트 권한이 없는 교사는 대신 전시 링크와 작품 목록을 안내할 수 있습니다.

## 음성과 비용

직접 WebRTC mesh를 사용하며 동시에 최대 6명이 음성에 동의할 수 있습니다. 각 참가자는 최대 5개 peer 연결을 가집니다. 음성 듣기와 마이크는 별도 버튼이며 microphone permission은 직접 클릭할 때만 요청합니다. 실패해도 글 대화와 관람을 유지합니다. 녹음·자동 전사·서버 음성 보관은 구현하지 않습니다.

기본 ICE 서버 목록은 비어 있습니다. STUN/TURN, 유료 음성 SDK·중계 서비스·외부 계정을 만들지 않습니다. 로컬 실제 Chrome의 두 격리 브라우저에서 합성 마이크의 양방향 DTLS/Opus 및 decoded waveform을 검사했습니다. 이는 실제 마이크·스피커, 서로 다른 인터넷 NAT/방화벽 또는 TURN 성공을 증명하지 않습니다. 네트워크가 직접 연결을 막으면 글·무음 관람을 사용합니다. 광역 운영 음성 지원에는 별도 중계·비용·개인정보 설계와 검증이 필요합니다.

새 유료 provider 자원은 없으며 전체 프로젝트 비용 상한은 별도로 관리합니다. 서버 socket/signaling은 기존 플랫폼 자원을 사용하므로 기존 hosting 비용이 0이라고 단정하지 않습니다. 직접 mesh가 server media bandwidth를 없애지만 참가자의 업로드 대역폭·CPU는 peer 수에 따라 증가합니다.

## 신고·차단과 보관

방은 최대 20명, 연결 세션은 30분, 연결 끊김 예약은 30초입니다. 재연결 token은 회전하며 브라우저 메모리에만 둡니다. 재연결 뒤 마이크·글·따라가기 동의는 자동으로 복원되지 않습니다.

차단은 해당 상대의 글·음성 전달을 제한하고 양측 RTC를 정리합니다. 차단 목록은 세션 내 최대 20명입니다. 신고는 spam/abuse/other와 240자 메모를 포함하며 호스트에게만 보입니다. 호스트는 개별 음소거·전체 음성 정지·퇴장을 수행할 수 있습니다. 신고를 외부 기관에 자동 전송하지 않습니다.

글은 최대 240자, 최근 30개·15분 한도입니다. 신고는 최근 20개·최대 24시간 한도이며 서버 프로세스의 메모리와 해당 방 생명주기 안에서만 존재합니다. 영구 감사 저장이나 법적 보관 시스템이 아닙니다. 방 정리·프로세스 종료 시 유지되지 않으며 Git/서비스 DB 백업에 포함되지 않습니다. participant 이름은 임시 방문객 이름이고 개인 계정 ID/세션 cookie/원본 작품 경로는 공개 snapshot에 넣지 않습니다. WebRTC signaling은 상대에게 네트워크 연결 정보를 제공하므로 직접 음성 동의를 안내하세요.

## 생명주기와 검증

나가기, 숨긴 탭, 작품 상세·안내 열기, 호스트 음소거, 역할 철회, 전시 접근 철회와 dispose에서 실제 microphone tracks/RTC/audio를 닫습니다. 돌아와도 자동으로 microphone permission을 요청하지 않습니다.

`npm run check`, `npm run test:e2e`, Docker/Chromium을 갖춘 `npm run test:opening`과 설치된 Chrome용 `EXHIBITOS_VOICE_CHROME=1 npm run test:voice-transport`를 사용합니다. 합성 검증은 실제 OS/기기/화면 읽기 또는 WAN/TLS qualification을 대신하지 않습니다. 전체 Phase2 출시 gate는 별도로 유지됩니다.
