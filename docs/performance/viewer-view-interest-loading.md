# View-interest artwork loading and working set

Implementation candidate: use one camera-derived working-set preference for
artwork scheduling, eligible quality warmth and memory reclamation. Source and
synthetic checks do not establish physical RAM/GPU savings, faster frame time,
actual phone acceptance or public delivery.

Visible physical footprints and explicit travel/viewing pins request required
minima. Connected-room topology is a candidate/retention hint rather than an
entitlement to load every neighboring artwork or to block visible full quality.
Existing partial-footprint wall/corner rays preserve works visible through doors.
An expanded projection (horizontal/vertical projection coefficients multiplied by
0.75), existing six-metre preparation range, and visible nearby doors identify at
most two optional next-view works. These do not block visible detail promotion.

Desktop additionally queries the existing bounded shadow pass for at most two
offscreen artwork revisions whose metadata bounds can project onto camera-visible
receiver regions, clipped to the actual fitted capture and light frustum. This
uses the actual directional or spot shadow camera, XY overlap and light-depth
ordering. Receiver regions are conservative bounding approximations, especially
for perspective spots; metadata does not guarantee a decoded mesh will cast.
Compact/disabled/unavailable maps request none. These soft dependencies follow
visible minima and attended quality, precede speculative preparation, and never
block full promotion or add pins. Candidate/admitted/deferred metadata counts
remain separate from actual 64-caster/100k-triangle omissions. Unchanged camera
and capture reuse receiver-region calculations. Ordinary source/tier/budget and
stale-queued rules still apply.

The existing 200 ms demand cadence continues advancing dwell, admission and task
settlement even when the camera is stationary. Static placement assertion bounds
are cached against their actual world matrix; wall group references are reused.
Cold bounds are rejected by current/expanded frusta before expensive wall rays.
Changes in visibility and world pose remain respected.

Queued work receives reversible priority overrides from the same interest:
pins/current, visible, next/recent, connected, cold. Compatible pending transfers
continue without restart and cancellation retains unsettled reservations.
Unseen, unpinned, nonmanual queued minima without a displayed owner can retire
after 1800 ms of cold interest; running compatible work is not cancelled by this
rule. Previously requested cold artwork is not automatically re-enqueued. The
normal 300 ms promotion / 1800 ms demotion grace remains. An already attached
full tier keeps its grace when attention changes; grace cannot promote a coarse
tier or override pressure reclamation or device/scene limits.

Explicit pressure reclamation discards unpinned encoded bodies by interest then
actual cache recency, and speculative prepared objects by interest then last
usefulness. It stops when the live deficit is solved. Existing cache-capacity LRU
and hard pins remain; soft interest grants neither authority nor a new pin.
Required displays, original-detail ownership, retained minimum borrowing and
ready-before-swap replacement keep their existing guards. No capacity is raised. Diagnostic minimum-room IDs cover the placement rooms of required artwork
revisions/pins rather than the connected-room search window. A shared artwork
revision can have multiple placements; this does not claim each one is visible.

An optional decoded result refused by the resident budget records only its
measured modeled allocation cost and exact inventory/policy/request identity.
Unchanged insufficient headroom blocks repeated decode/discard attempts. Useful
reclamation or a changed identity/policy can permit another request; newly
required minima use their established recovery path. This is not cached rights:
ordinary source, integrity, expiry and authority checks still run on actual reuse
and attachment. Selected/original detail remains a separate owner and policy.

Expected benefits are fewer invisible compulsory loads, less avoidable full/coarse
churn, and retaining more useful reusable data under pressure. Existing R97
calibration establishes that expendable encoded bodies exist; it does not measure
forced eviction, this candidate's savings, driver program storage or physical
memory. Actual affected qualification must distinguish request/decode/cache
changes and modeled ledger bytes from draw/quality observations and frame time.
The independently qualified shadow/contact candidate does not close this broader
loading/memory completion unit.
