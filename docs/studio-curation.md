# 공간 오디오·시간 대본·추천 안내 동선

개발 후보입니다. 실제 통합 검사 결과가 확정되면 아래에 기록합니다.

Studio에서 로컬 전시를 선택하고 **관람 오디오와 작품 설명**에서 승인된
WAV 음성과 원문을 연결합니다. **공간 오디오·시간 대본·안내 동선** 편집은
원문과 별도 번역을 저장하며, 기존 로컬 저장·서버 revision·READY·명시적
공개·철회 흐름을 사용합니다. 공개 이력이 있는 revision은 새 draft로
복제한 뒤 수정합니다. 계정 없는 로컬 글 편집도 가능합니다.

- 구역을 선택해 기준/최대 거리, 감쇠 계수와 벽 차폐 여부/비율을 적용합니다.
  **거리·차폐 기본값으로**는 원래 구역을 보존하고 선택 설정만 제거합니다.
  구역의 반경과 거리 감쇠 최대값은 별개입니다. 구역 진입 재생은 관람자가
  별도로 선택해야 하며 전시를 열 때 자동 재생하지 않습니다.
- 음성을 선택하고 승인된 WAV의 정확한 전체 길이와 각 대본의 시작/끝·글을
  입력합니다. 구간은 음성 길이 안에서 순서대로 겹치지 않아야 합니다.
  원문/번역 구간을 각각 선택해 갱신·삭제할 수 있습니다. 번역 언어는 원문과
  달라야 합니다. 전체 원문 대본은 그대로 남으며 서버가 실제 파일 길이와
  대조합니다. 지원 한도는60초·128구간·16개 번역입니다.
- 기존 위치 주석을 선택해 작품 중심 기준 미터 좌표와 원문을 수정하거나,
  언어별 번역을 추가·갱신·삭제합니다. 좌표가 실제 작품 치수를 벗어나면
  변경을 적용하지 않습니다. 주석 삭제 시 해당 위치/번역만 함께 제거합니다.
- 추천 동선 이름·방·미터 좌표·정류점 제목/글 설명을 입력해 정류점을
  추가합니다. 다른 방으로 연결할 때 실제 연결 문을 선택합니다. 기존
  정류점의 연결 문은 선택·수정 과정에서도 유지됩니다. 순서를 바꾸거나
  정류점/동선을 삭제할 수 있으며 관련 작품은 선택 사항입니다.

관람은 무음 글·목록 방식으로 시작합니다. **안내 시작**을 선택하면 작가가
작성한 순서대로 정류점의 글을 읽을 수 있고 전체 글 안내도 펼칠 수 있습니다.
이전/다음 조작은 공간 이동을 강요하지 않습니다.3D에서 정류점의 정지 시점을
보는 조작은 별도 버튼이며 보행·포인터 캡처·소리를 자동 시작하지 않습니다.
작품 상세의 전체 원문·시간 구간·번역·위치 주석은 소리 실패/음소거에도
읽을 수 있습니다. 실제 음성 재생 중 구간 표시는 AudioContext 재생 시간을
따르며 정지·종료하면 현재 구간 표시를 해제합니다.

차폐는 직선과 변환된 벽/바닥/천장 평면의 교차 및 실제 문/창문 개구부를
이용한 근사입니다. 회절·반사 전파·실측 음향을 계산하지 않습니다. 작성된
동선의 물리적 접근성/건축 규정 적합성을 인증하지 않으며 글 안내가 정지
대체 관람을 제공합니다. 실제 스피커·마이크·모바일은 별도 지원 검사입니다.

새 optional curation v1의 정확한 형식/참조/한도는
[shared contract](../packages/studio-contract/src/curation.ts)와
[ADR0017](adr/0017-curated-experience.md)에 있습니다. 공개 기본 OES 규격은
변경하지 않았습니다. 오래된 소비자는 이 선택 확장을 무시할 수 있고,
이전 Platform의 닫힌 OEX 프로필은 새 확장을 지원하기 전 거부할 수 있습니다.
원문/주석/번역/동선은 DB revision과 IndexedDB 안에 저장되므로 Git bundle
백업에 포함되지 않습니다. 지속 데이터는 기존 일관된 암호화 서비스 백업과
새 환경 복원 절차를 사용하세요. 기존 원본·기록·백업을 자동 삭제하지 않습니다.

검사 명령은 `npm run check`, `npm run test:e2e`, `npm run test:curation`입니다.
마지막 명령은 Docker와 Chromium으로 합성 WAV의 실제 업로드·승인, Studio
편집·저장·공개, 재생 시간 대본과 무음 키보드 안내, 별도 DB 복원을 실행합니다.
명령을 문서에 적은 것 자체는 통과 증거가 아닙니다.
