# 목록과 3D 관람

공개 전시는 글·목록으로 시작합니다. 작품 설명, 실제 치수, 재료·제작 연도,
권리·출처, 공개 이력, 번역과 작가 음성 대본을 3D 이동 없이 읽을 수 있습니다.
등록되지 않은 정보는 미기록으로 표시합니다. 이 화면은 작품 모델·이미지·WAV를
미리 요청하지 않습니다.

`3D 관람 시작`을 선택하면 전시 공간을 불러옵니다. 걷기와 소리는 각각 명시적으로
시작합니다. `글·목록 관람으로 돌아가기`는 3D와 소리 실행을 종료하고 입구 버튼으로
포커스를 돌려줍니다. 브라우저가 3D나 마우스 시점 잡기를 지원하지 않아도 목록을
사용할 수 있습니다.

Tab으로 링크·버튼·설정을 이동하고 Enter 또는 Space로 실행합니다. 전시 시작 안내,
크레딧과 작품 상세는 dialog이며 Esc로 닫거나 닫기 버튼을 선택할 수 있습니다.
닫으면 실행한 버튼으로 포커스가 돌아갑니다. 작품 목록 순서 안내는 공개 전시에
기록된 배치 목록 순서이며, 작가가 지정한 공간 동선과 다를 수 있습니다.

움직임 줄이기는 운영체제 설정을 따르거나 직접 선택할 수 있습니다. 고대비 설정은
관람 인터페이스의 글·버튼·포커스에 적용하며 작품의 원래 색을 바꾸지 않습니다.
목록의 대본은 소리를 켜지 않아도 읽을 수 있습니다. 목록 관람에서 실제 음성 재생을
원하면 3D를 시작한 뒤 상세 보기의 음성 버튼을 사용합니다.

검사는 `npm run test:accessibility`로 실행합니다. 실제 공개 승인 합성 전시와
production Chromium을 사용하며 자동 키보드·DOM/ARIA 검사와 실물 화면 읽기 도구
검증을 구분합니다. 테스트 프로토콜은 [accessibility-protocol.md](accessibility-protocol.md)를
읽으세요. 구현 중인 단계이며 검사 결과 없이 WCAG 적합성·실물 모바일 지원·MVP
전체 성능 완료를 주장하지 않습니다. 기존 [Viewer 수치와 제한](performance/viewer-baseline.md)은
목록 성능과 별개의 3D 측정 결과입니다.
