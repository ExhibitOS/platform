# 소리·작품 상세·작가 음성

상태: 구현 후보, 전체 통합 검사 진행 중. 실제 검증 범위는 후속 결과 기록을 따르며 현재 완료 선언이 아닙니다.

## 작가와 전시 편집자

1. CMS에 로그인한 뒤 Studio의 전시를 로컬 및 서버에 저장합니다. 서버 연결이 같은 사용자·기관일 때 전시 오디오를 사용할 수 있습니다.
2. **작가 음성 녹음 시작**을 직접 선택하면 브라우저가 마이크 권한을 요청합니다. 본인이 공식 브라우저 화면에서 허용해야 하며, 권한을 주지 않아도 파일 업로드와 글 설명을 사용할 수 있습니다. **녹음 정지·WAV 준비** 또는 **녹음 취소**로 마이크를 닫습니다. 최대60초이며 자동 업로드하지 않습니다. 미지원 장치는 PCM WAV 파일을 선택하세요.
3. 파일은 PCM16 mono/stereo8–48kHz,60초·12MiB 이하입니다. MP3/OGG/부가메타데이터 WAV는 현재 업로드 프로필에 포함하지 않습니다. 권리자·크레딧·라이선스와 본인 공개 재생 허용을 입력하고 **오디오 업로드·검증**을 선택합니다. 오류 시 권리와 같은 파일로 재시도할 수 있습니다.
4. 목록에서 **오디오 승인**을 명시적으로 선택합니다. 승인 파일을 작품 배치·언어·대본에 연결하거나 작품 위치의 공간 오디오로 추가합니다. 바닥 재질·공간 울림, 작품 중심 미터 좌표의 위치 설명과 별도 번역도 편집할 수 있습니다.
5. 현재 입력을 로컬 및 서버에 저장하고 READY 검사를 거쳐 명시적으로 공개합니다. 공개 이력이 있는 immutable snapshot을 직접 편집하지 말고 새 draft를 만드세요.
6. **오디오 공개 재생 철회**는 해당 오디오를 포함한 공개 전시 metadata/bytes 접근을 막습니다. 저장된 원본/승인/공개 기록을 삭제하지 않습니다. **복원**은 현재 권리가 유효할 때만 가능합니다. 이미 전달된 bytes의 원격 삭제나 DRM은 보장하지 않습니다.

## 관람자

전시는 무음으로 열립니다. **소리 켜기**, 작품의 음성 버튼 또는 공간 오디오 버튼을 직접 선택해야 시작합니다. 음소거·음량·정지 조작을 사용하세요. 권한·파일·브라우저 오류가 있으면 대본과 원문을 계속 읽을 수 있습니다. 마이크는 관람 중 요청하지 않습니다.

바닥 발소리는 실제 걷기 거리와 재질을 따르며 정지·시점 회전만으로 발생하지 않습니다. 공간 오디오는 명시적으로 선택한 구역 안에서 거리별 음량과 방 크기의 근사 울림을 사용합니다. 로딩은 현재·다음 작성 순서의 방과 제한된 재생 파일만 대상으로 합니다. 모든 전시 파일을 미리 내려받지 않습니다.

작품 목록의 상세 버튼 또는3D 작품 선택으로 상세 보기를 엽니다. 확대·회전·실제 치수·재료·공개 이력·권리·원문/번역·음성 대본·위치 설명을 볼 수 있습니다. CMS에서 작가가 입력하고 승인한 제작 연도·재료를 표시합니다. 공개 기록에 없는 연도나 재료는 미기록으로 표시하며 등록·승인·게시 날짜로 추정하지 않습니다. 자동 접근 상세 전환은 기본 꺼짐이며 선택해 켤 수 있습니다. Esc 또는 닫기로 기존 카메라 위치와 초점으로 돌아갑니다. 마우스 캡처는 자동으로 다시 잡지 않습니다. 전시 시작 안내와 크레딧은 별도 안내 화면에 있습니다.

## 운영과 제한

[오디오 API](../contracts/audio-openapi.json), [ADR0011](adr/0011-viewer-audio-detail.md)를 따릅니다. 브라우저 decoded cache24MiB는 실제 기기 process/RSS 측정이 아닙니다. 실제 마이크·스피커, 모바일·GPU 검증 결과는 확인한 범위만 별도로 기록합니다. 오디오 원본·승인·publicmedia·DB/blob/브라우저 draft는 Git bundle 백업에 포함되지 않습니다. 새 지속 데이터는 maintenance-window DB dump와 모든 object inventory/hash를 함께 백업하고 별도 빈 환경에서 복원해야 합니다. 기존 데이터·백업 자동삭제는 없습니다.


로컬 전체 검사는 `npm run test:experience`로 실행합니다. macOS에서 bundled Chromium의 권한 거부 경로가 `NotSupportedError`를 반환하면 설치된 Chrome의 격리 프로필로 거부 검사만 선택할 수 있습니다: `EXHIBITOS_EXPERIENCE_DENIAL_CHANNEL=chrome npm run test:experience`. 성공 녹음 검사는 가상 입력·출력 장치와 허용용 테스트 UI를 사용하고, 거부 검사는 별도 브라우저에서 그 UI 우회를 제거한 실제 permission denial/NotAllowedError를 요구합니다. 두 검사는 `getUserMedia`·AudioWorklet·실제 PCM 샘플과 타이머를 사용하며 물리 마이크·스피커나 OS 개인정보 대화상자를 검증하지 않습니다.
